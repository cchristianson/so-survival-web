Share with nearby devices

Other phones, tablets, and computers on the same local network can open this library in a browser. Internet is not required: the search and the AI run on this device. iPhones too.

No Wi-Fi? Turn on a phone's hotspot (mobile data can stay off) or use a small travel router, and connect this device and the other phones to it. If Windows or the Mac asks whether to allow network access, choose Allow.

ARK Vault

A battery-powered library that nearby devices can use without internet. A steel ammo can holds this library on a small computer (a Raspberry Pi), a battery, the chargers to fill it from the sun or the wall, a little printer, a crank radio and an old phone to read it on. Open the lid and flip the power switch on, and any phone nearby uses the library and the AI over the Vault's own Wi-Fi.

Read the build guide See it in 3D

The guide has the parts list, the files to 3D-print and laser-cut, the wiring, and how the setup tool prepares the Pi so it sets itself up.

Vault system status

Updates every few seconds. Look at it while the AI is answering: when it has nothing to do, a Pi runs slowly on purpose to save power.

Complete offline library (USB)

Every book, all of Wikipedia, maps that work with no signal, and an AI that needs no internet. Download the setup tool, choose a drive, and select the library content you want.

  1. Download and unzip the setup tool.
  2. Run the installer for your operating system (INSTALL-Windows or INSTALL-Mac).
  3. Select a drive and start the download.

Download the setup tool

One zip, about 40 MB (the installer kit) · Windows, Mac, Linux. The zip is the installer, not the whole library.

You can run the installer again and continue an interrupted download: pick the same drive and press Continue.
